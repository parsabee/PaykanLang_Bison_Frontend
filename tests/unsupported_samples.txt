# The samples of PaykanLang's corpus (share/paykan/samples) that the bison
# frontend does not accept, because they use generics (README, "Generics are
# not supported") or syntax outside its grammar.  One per line: the category,
# then the path relative to the corpus.
#
#   generics  the program declares or uses user-defined generics; the bison
#             frontend reports exactly one diagnostic, "generics are not
#             supported by the bison frontend; use --frontend=recursive-descent"
#   syntax    core samples written in syntax outside this frontend's grammar;
#             Bison rejects them with a syntax error
#
# FrontendDifferential and SamplesFrontendParity skip these files, and
# UnsupportedSamples checks that each one is rejected that way (and is still
# accepted by recursive-descent).  The list was made from the files on which
# the two frontends differ; a program in both categories is listed under
# the one the bison frontend reports first.
